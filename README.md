## Setup

### 1. Clone The Repository

```bash
pkg install git
git clone https://github.com/KillerSharmaBot/sso.git
cd sso
```

### 2. Install Python (3.8+)

```bash
pkg install python
```

### 3. Install Dependencies

```bash
pip install flask requests
```

### 4. Start The app

```bash
python app.py
```

### 5. Open Browser

```
http://127.0.0.1:5000/
```
